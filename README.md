## `01 / About`

I'm an Information Technology engineering student interested in the engineering behind useful AI: how models are trained, evaluated, served, and integrated into real applications.

My work spans machine learning, computer vision, backend APIs, and full-stack development. I enjoy projects that combine experimentation with practical system design — from detecting defects in railway imagery to thinking about how multiple AI models can share limited GPU resources.

- **Currently exploring:** ML model development, computer vision, and AI inference infrastructure
- **Interested in:** Model evaluation, efficient inference, scheduling, and reliable software
- **Approach:** Understand the problem, build a baseline, measure the results, then iterate
- **Open to:** Meaningful collaborations, engineering internships, and challenging projects
